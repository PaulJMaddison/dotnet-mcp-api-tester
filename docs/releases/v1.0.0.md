# Dotnet MCP API Tester v1.0.0

Point an AI coding agent at an OpenAPI contract and give it an API test engineer.

This first release provides:

- free-text API queries grounded in structured OpenAPI RAG
- deterministic parameter and edge-case generation
- safe live HTTP execution with dry-run and policy controls
- an in-memory vector store with no vector infrastructure
- Azure AI embeddings and reasoning
- Claude Code and Codex support

Install the `PaulJMaddison.DotnetMcpApiTester` .NET global tool and register `mcp-api-tester` with your coding agent. Azure configuration remains local to the MCP process.
